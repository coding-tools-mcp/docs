Coding Tools MCP Desktop 是 macOS、Windows 和 Linux 的原生应用。它把官方 `coding-tools-mcp` core 包在一个图形界面里：创建工作区、选择运行时、启动和停止服务、可选地通过隧道对外暴露——全程不需要编辑配置文件。源码和原生安装包在 [coding-tools-mcp/desktop](https://github.com/coding-tools-mcp/desktop)。

![运行中工作区的 Dashboard](/images/desktop/dashboard-running.png)

## 安装

1. 从 [desktop 仓库](https://github.com/coding-tools-mcp/desktop)安装原生包，或按 README 自行构建。
2. 打开 **Settings**，选择 **Install recommended Core**。内置安装器会下载私有 Python 和所选的官方 Core，无需自己安装 Python 或 uv。新建工作区向导中的 **Use existing Core** 可以跳过这一步下载。
3. 只有需要公开分享工作区时才安装 [cloudflared](https://developers.cloudflare.com/cloudflare-one/networks/connectors/cloudflare-tunnel/downloads/)。仅本机使用的工作区不需要其他依赖。

![Settings：语言、外观、关闭到托盘、Core 安装管理](/images/desktop/settings.png)

## 创建工作区

点击侧边栏的 **New workspace**，向导共三步：

1. **Choose folder** — 工作区名称和工具可访问的绝对路径。
2. **Access** — 客户端如何连接这个工作区（见下文）。
3. **Review workspace** — 确认并创建。

![New workspace 向导的文件夹步骤](/images/desktop/new-workspace.png)

底部的 **Permission mode** 开关用于选择 `Safe`（默认值，更严格的执行检查——并不是只读）或 `Trusted`，后者需要你显式确认，只用于可信代码。

### 访问方式

| 访问方式 | 公网地址 | 适用场景 |
| --- | --- | --- |
| **Only this device** | 无——仅回环地址 | Claude Desktop、Cursor、MCP Inspector 等本机客户端 |
| **Temporary sharing** | Quick Tunnel `*.trycloudflare.com`，每次重启都会变化 | 短期分享和演示 |
| **Stable public access** | 通过命名 Cloudflare 隧道绑定自有域名 | 固定 URL 和浏览器登录 |
| **FRP / existing HTTPS proxy** | 外部自行管理的代理路由 | 自己维护代理的情况 |

两种 Cloudflare 方式都需要 `cloudflared`。命名隧道可以在浏览器里完成 Cloudflare 授权，并在你确认后自动创建隧道和 DNS 路由。隧道失败不会影响本地服务。

![向导的 Access 步骤，选中 Temporary sharing](/images/desktop/workspace-access.png)

## 认证方式

公开访问必须选择一种认证方式。凭据留空时，保存后会自动生成。

| 方式 | 客户端发送 | 适用场景 |
| --- | --- | --- |
| **Bearer token**（默认） | `Authorization: Bearer <token>` | 客户端可以设置请求头 |
| **Token in URL** | URL 中的 `?token=<token>` | 客户端只接受一个 URL，例如 ChatGPT 连接器或简单嵌入——同一令牌也可作为 Bearer 头使用 |
| **Username and password** | HTTP Basic 认证 | 客户端提供用户名/密码登录 |
| **Browser sign-in (OAuth)** | 使用工作区密码的 OAuth 流程 | 仅在有固定地址时可选（命名隧道或 FRP） |

![认证选项：Bearer token、Token in URL、Username and password](/images/desktop/authentication-options.png)

**Copy endpoint** 复制可直接使用的 URL——Token in URL 模式下已经带 `?token=`。Connections 页的 **Copy config** 生成对应的客户端配置，**Show credentials** 显示已保存的凭据。`?token=` 在转发给 core 前会被剥离，不会出现在 core 日志中。任何模式下 `/.well-known/` 发现接口都保持公开。

## 运行与监控

**Dashboard** 显示 CPU、内存、运行时长和 Core 版本，并有 **Local service** 与 **Public access** 两张独立的健康卡片，可在此启动、停止、重启工作区。

- **Connections** — 两个端点及复制按钮、**Check public address**、隧道提示和命名隧道部分。

  ![Connections 页面](/images/desktop/connections.png)

- **Activity** — 最近的工具调用，可按结果过滤。已发布的 Core 0.5.0 不暴露事件日志，因此显示 *Tool history unavailable* 属于预期；工具本身正常运行。

- **Diagnostics** — **Run checks** 检查运行时、文件夹权限和连通性；**Export diagnostics** 生成脱敏报告；运行时和隧道日志中的凭据已打码。

  ![Diagnostics 页面，显示脱敏后的运行时日志](/images/desktop/diagnostics.png)

- **Settings** — 语言（English / 简体中文）、明暗外观、**Close to tray**（关窗后服务继续运行）以及 Core 版本安装与回滚。

## 连接客户端

从 Dashboard 或 Connections 页复制端点或客户端配置，粘贴到 MCP 客户端中。各客户端的详细说明见[客户端配置](/zh-CN/clients)。ChatGPT 通过 Plugins → Add → Custom MCP server 接受自定义 MCP 服务器：粘贴 Token in URL 端点并选择 **No authentication**，或让 **Stable public access** 的工作区走 OAuth 流程。凡是只接受 URL 的 MCP 客户端都可以用 Token in URL；下图中 MCP Inspector 通过隧道列出了工作区目录：

![MCP Inspector 连接工作区后列出目录内容](/images/desktop/inspector-list-dir.png)

隧道和网络背景见[远程访问](/zh-CN/guides/remote-access)。
