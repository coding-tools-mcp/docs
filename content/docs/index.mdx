Coding Tools MCP is a model-neutral coding runtime served over the Model Context Protocol. It gives MCP clients file access, structured code changes, command execution, interactive processes, and Git operations inside one configured workspace.

## Start here

- [Quickstart](/getting-started) — install the runtime and connect your first client.
- [Client configuration](/clients) — configure ChatGPT, Claude, Cursor, VS Code, and other MCP hosts.
- [Remote access](/guides/remote-access) — expose a local runtime through an authenticated HTTPS tunnel.
- [Docker sandbox](/guides/docker-sandbox) — run untrusted work in a disposable container.
- [Troubleshooting](/troubleshooting) — diagnose protocol, transport, and runtime problems.
- [Ecosystem & community projects](/ecosystem) — discover official companion projects and community-maintained downstreams built on Coding Tools MCP.

## Project repositories

The core runtime remains at [xyTom/coding-tools-mcp](https://github.com/xyTom/coding-tools-mcp). The desktop application is maintained separately at [coding-tools-mcp/desktop](https://github.com/coding-tools-mcp/desktop).

Source-coupled contracts and evidence stay in the core repository. See [Reference](/reference) for the authoritative locations. Community-maintained extensions and downstream distributions live in [Ecosystem](/ecosystem), where official and third-party projects are kept clearly separated.
