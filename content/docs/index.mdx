Coding Tools MCP is a model-neutral coding runtime served over the Model Context Protocol. It gives MCP clients file access, structured code changes, command execution, interactive processes, and Git operations inside one configured workspace.

## Learn the mental model first

The most important documentation page for a new user is [Choose your setup](/getting-started/choose-your-setup). It separates three questions that are easy to confuse:

- where the runtime runs;
- how the client reaches it;
- how access and execution risk are controlled.

That separation prevents the most common mistakes: treating a tunnel as a sandbox, treating `safe` mode as read-only, or debugging workspace permissions when a cloud client never reached the server.

## Project repositories
