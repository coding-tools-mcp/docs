Coding Tools MCP 是一个通过 Model Context Protocol 提供服务的模型中立 coding runtime。它让 MCP 客户端能够在一个配置好的工作区内访问文件、执行结构化代码修改、运行命令、维护交互式进程并执行 Git 操作。

## 先建立正确的心智模型

新用户最应该读的是[选择你的使用方式](/zh-CN/getting-started/choose-your-setup)。它把三个容易混淆的问题分开：

- runtime 跑在哪里；
- 客户端如何连接它；
- 如何控制访问和执行风险。

这种拆分能避免最常见的错误：把隧道当成沙箱、把 `safe` 模式当成只读，或者在云客户端请求根本没到 server 时误查 workspace 权限。

## 给 AI agent 使用

文档站也发布机器友好的 Markdown：

- [`llms.txt`](/zh-CN/llms.txt) — 文档的紧凑索引。
- [`llms-full.txt`](/zh-CN/llms-full.txt) — 一次返回完整文档语料。
- 每个文档页面顶部都有 **Copy Markdown / View options**，可以直接查看 Markdown。

当 agent 需要项目文档、但不适合解析渲染后的网页时，使用这些 endpoint。

## 项目仓库

核心 runtime 仍在 [xyTom/coding-tools-mcp](https://github.com/xyTom/coding-tools-mcp)。桌面应用单独维护在 [coding-tools-mcp/desktop](https://github.com/coding-tools-mcp/desktop)。

与源码耦合的 contract 和证据保留在核心仓库。权威位置见[参考](/zh-CN/reference)。社区维护的扩展和下游发行版放在[生态系统](/zh-CN/ecosystem)，官方项目与第三方项目会明确区分。
